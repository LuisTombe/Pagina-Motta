# Carpeta de Evidencias Públicas (`evidencias/`)

Coloca aquí los archivos de los 13 anexos junto con el archivo `manifest.json` (generado desde el botón **"Compartir / Publicar"** de la página) y súbelos al repositorio con `git add evidencias && git commit -m "docs: publicar evidencias" && git push origin main main:gh-pages`.

Cualquier persona que abra `https://luistombe.github.io/Pagina-Motta/` en cualquier computador verá, previsualizará y descargará automáticamente todos los anexos publicados aquí.
